# Phase 8 — Production hardening

Reused all existing modular services, exact-money/QR/accounting controls, protected audit, application screens and real database tests. Added forward-only reporting/foreign-key indexes, nonblocking PostgreSQL number sequences preserving original numbers, and absolute timestamp types preserving Prisma UTC instants.

Implemented: standalone Next.js packaging; Docker/Compose with separate migration owner/application role, database/app health and local Caddy TLS; PWA manifest/local-only fallback with API cache exclusion; HTTP LAN cryptographic request keys; persisted uncertain checkout intent/reload recovery; scanner autofocus/Enter; thermal and report PDF printing with explicit error handling; bounded streaming requests; login/session review; isolated test configuration; real manual/scheduled/event-closing backups with CAS claims, streaming checksums/downloads and safe fresh-database restore; reviewed dependencies, formatting, CI and operator/deployment/security/recovery documentation.

Validation found and corrected: accidentally expanded cashier menu entries, secure-context-only request UUIDs, counter/index contention under ten concurrent checkouts, and UTC-hour report labels. Ten independent checkouts subsequently committed in 342 ms with zero failures and a 21 ms reconciled report on the development host. Historical financial IDs, amounts and snapshots were retained. Number sequences can have rollback gaps and remain globally increasing across date prefixes.

Final gates and full acceptance evidence reside in `validation/phase-8` and `validation/final`. The final suite checks all four roles/two stations, invalid/blocked/reissued QR, exact PromptPay/payment/allocation/receipt, duplicate handling, voids, unauthorized access, lost-response/reload retry, printer failure, event closing, CSV/PDF, Internet-independent browser requests, backup workers, restore and ordinary HTTP LAN operation. Known target-host conditions are documented in the final report; Docker, a live institutional bank recipient and physical peripherals are not certified by local automation.
